**Context:** When a show's details are updated in the system, we want to push the new show data to all subscribed clients in real-time. You will need to handle a new type of GraphQL operation: `subscription`.

This function should parse the request, create an instance of your new subscription tracking struct, and store it in a suitable collection (e.g., a hash map).
