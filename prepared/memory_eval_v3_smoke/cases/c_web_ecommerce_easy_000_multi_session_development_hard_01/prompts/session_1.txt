**Instructions:** Design and implement the necessary database schema changes. **Goal:** Integrate the flash sale data into the product catalog.
**Instructions:** Welcome back. Using the database functions you created in the previous session, modify the `catalog_service.c` file. **Goal:** Address performance issues and make the feature production-ready.
**Instructions:** You've implemented the core logic, but repeatedly querying the database for sales on every product view is inefficient. Your task is to refactor the caching mechanism to support flash sales. The system must ensure that a product's cached data is invalidated as soon as its flash sale ends. You will need to modify `src/core/cache.c` and how it is used in `src/services/catalog_service.c` to achieve this. The solution should be efficient and reliable.
